## R++

- this is my first attempt of creating a compiler for my own programming language written entirely in C. 
- literally all this does right now is print() 

## Current Language Documentation

- print()
	- this function displays what is enclosed inside the parantheses 
	- currently the print function only supports numerical expressions, such as 5 + 5, and does not have support for strings yet
	- additionally, the only operators that are currently supported are +, -, *, and /
